## Featured projects

### 📚 [LeafMark](https://github.com/jlage24/ESOF-Leafmark)
A mobile app for exchanging physical books, built with Flutter. I lead the project as tech lead and CPO, working with a team of four on sprint planning, architecture, and implementation. One highlight: tracking down a stream lifecycle bug that was quietly breaking things across eight files.
`Flutter` `Dart` `Firebase`

### 🏋️ [Flow Fitness](https://github.com/jlage24/LTW-Flow-Fitness)
A gym management web app with membership billing, class scheduling with waitlists, equipment tracking, and an analytics dashboard, for three user roles (member, trainer, admin). Built without frameworks for a university web technologies course, with a hand-rolled layered CSS setup.
`PHP` `SQLite` `JavaScript` `AJAX`

### 🔪 [Murder Mystery](https://github.com/jlage24/LDTS-Murder-Mystery)
A terminal-based mystery game inspired by Cluedo. Players explore a mansion, gather clues, and try to name the correct suspect, weapon, and room before the culprit hunting them down catches up.
`Java`
